# Marketing_Analysis
Marketing data analysis project focused on evaluating campaign performance, customer behavior, and key KPIs to support data-driven marketing decisions using data visualization techniques.
## 📌 Overview
This project focuses on analyzing marketing data to evaluate campaign performance, understand customer behavior, and identify opportunities to improve marketing effectiveness.  
The analysis aims to support data-driven marketing decisions through clear insights and visualizations.

---

## 🎯 Business Objective
- Measure the effectiveness of marketing campaigns
- Identify high-performing channels and customer segments
- Analyze conversion performance and customer behavior
- Provide actionable insights to improve marketing ROI

---

## 📂 Dataset
- **Source:** Marketing campaign dataset
- **Records:** 2237 rows
- **Time Period:** Jul 2012 – Jun 2014
- **Features Include:**
  - Campaigns interactive
  - Marketing channel
  - Customer demographics
  - Store purchasing, Website purchasing, Website visits
  - revenue

## 🛠 Tools & Technologies
- **Python:** Pandas, NumPy
- **Power BI:** Interactive dashboards
- **Excel:** Data validation and exploration

---

## 🔍 Analysis Performed
- Exploratory Data Analysis (EDA)
- Campaign performance comparison
- Conversion rate analysis
- Customer segmentation analysis
- Trend and seasonality analysis
- Cost vs Revenue & ROI analysis

---

## 📊 Key KPIs
- Total Revenue
- Web Conversion Rate %
- Average Recency
- Average Store & Web purchase

---

## 📈 Key Insights
- Certain marketing channels show consistently higher conversion rates
- Campaign performance varies significantly by customer segment
- High spend does not always correlate with high ROI
- Seasonal trends impact conversion and engagement rates
